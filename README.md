
# NOVA AI Workspace 🤖

NOVA is an AI chatbot workspace built using Python, Streamlit, Gemini AI, and MySQL.

## Features
- AI-powered conversations using Gemini AI
- Document Question & Answering
- Sentiment Analysis
- MySQL Conversation History
- Light and Dark Themes
- Save and Regenerate Responses

## Technologies Used
- Python
- Streamlit
- Google Gemini API
- MySQL

## How to Run Locally

1. Download or clone this repository.
2. Install dependencies:

   `pip install -r requirements.txt`

3. Create a local `.env` file with your Gemini API key and MySQL connection details.
4. Start the application:

   `streamlit run app.py`

## Security
Never upload API keys, database passwords, or `.env` files to GitHub.
